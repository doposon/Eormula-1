# Original car models for Blender

RB22.glb and SF26.glb are the unmodified, decompressed GLBs already embedded in the game. All meshes, textures, materials and original node transforms are retained. Import using File > Import > glTF 2.0 in Blender.

For wheel preparation, keep the original scale and orientation. Separate four wheel assemblies with origins at their axle centres. Name them WHEEL_FL, WHEEL_FR, WHEEL_RL, WHEEL_RR from the driver's perspective; keep steering pivots separate from rolling pivots where possible. Include tyres and rims in each rolling assembly; keep brake calipers out of the rolling assembly. Preserve CAMERA_COCKPIT if added. Export the whole car to GLB with textures.

These are source models for editing; independent wheel animation has not been added to the game yet.
