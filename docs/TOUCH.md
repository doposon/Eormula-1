# 触屏操控（手机 / 平板，横屏）

## 布局

| 位置 | 控件 | 等同于键盘 |
| --- | --- | --- |
| 右下角最右 | **GAS 油门** | 按住 `W` |
| 油门左边 | **BRAKE 刹车** | 按住 `S`（慢到停后倒车） |
| 左下角 | **◀ ▶ 转向** | 按住 `A` / `D` |
| 右上角，SETTINGS 旁边 | **摄像头图标** | 点一下 = `V` 切换视角 |
| 左上角 | **EXIT** | 点一下 = `Esc`（暂停 / 继续，回放中则返回） |

- 转向区是一个整体，手指可以在左右两侧之间直接滑动切换，不用抬手。
- 油门和刹车可以同时按住；多点触控互不影响。
- 键盘控制**完全没有改动**：触屏按钮发出的就是和键盘一模一样的按键事件，游戏原有的输入代码不知道区别。键盘和触屏可以同时使用。
- 只在比赛进行中显示。暂停、回放、退出到菜单时，油门 / 刹车 / 转向会隐藏并自动松开所有按键；EXIT 在暂停和回放时仍然显示，用来继续或返回。
- 竖屏时会提示“请将手机横屏使用”。

## 何时启用

- 触屏设备（主要指针为手指）自动启用；带鼠标的电脑不会出现任何触屏控件。
- 在地址后加 `?touch=1` 可强制开启（电脑上调试用），`?touch=0` 强制关闭。
- 启用后，为给按键腾位置，驾驶中会隐藏“下载离线 HTML”按钮，并把计时面板移到右上、速度表居中、胎温面板和帮助按钮上移。这些只在触屏模式下生效。

## 代码

- `src/touch-controls.mjs`：创建按钮、发送按键事件。`game.js` 启动时调用 `touchControls.init()`。
- `game.js` 的主循环每帧给 `<body>` 打上 `in-session`（已进入比赛）和 `drive-active`（正在驾驶）两个标记，样式据此显示或隐藏按钮。
- 样式在 `src/ui.css` 末尾，全部限定在 `body.touch-mode` 下。
- 测试：`npm i --no-save jsdom && node tools/touch.test.mjs`。
- 离线 HTML 导出已包含该模块；按钮文字已加入中文翻译。
