# 后续模型的座舱标记约定

本次只为已有 RB22 与 SF26 校准座舱。它们当前没有 `CAMERA_COCKPIT` 标记，运行时代码使用经过画面对比的位置；尚未实现任意新模型的标记读取。

以后在 Blender 中添加空物体 `CAMERA_COCKPIT`，放在驾驶员双眼中间的位置，略在头枕前面。名称大小写保持一致；每辆车只放一个。把空物体作为赛车根对象的子对象，保持它与赛车相同的缩放和变换层级，并确保导出 GLB 时包含它。

位置之外还需要朝向。建议约定空物体局部 **-Z 向前看，+Y 向上**（与 glTF 摄像机约定一致），不是只放一个点。可以在 Blender 打开轴向显示来确认。导出后要核对 GLB 节点是否仍存在；后续合并网格或归一化模型时不能丢掉该标记。

接入新模型时，应读取节点的完整父子变换，再与模型一同做缩放、方向与高度归一化，不能把原始 Blender 坐标直接当成游戏坐标。之后将相机绑定到车身，而不是单独在世界空间追随。

每次接入仍需画面验收：从 Halo 下方看得到前方赛道；不在头枕或头盔内；近裁切不会切掉方向盘；车身俯仰时标记与座舱相对位置不漂移。标记能减少猜坐标，但不能代替这些检查。
