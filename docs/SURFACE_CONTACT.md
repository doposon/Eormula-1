# 2.17.3 road contact

Scope: Spa asphalt height correction, Silverstone and Singapore kerb suspension. The user's final clarification identifies Singapore as the second kerb track. Shanghai's existing authored kerb lookup remains the reference implementation.

Previously, Spa drove on a 1.5m height raster reconstructed with Catmull-Rom interpolation. A hard raw-raster clearance floor could immediately reintroduce bumps after filtering. The game now builds a sparse spatial index of the original asphalt triangles when the original GLB loads and uses barycentric mesh height where asphalt exists. Raster terrain remains the fallback outside those meshes. Genuine hill elevation, banking, textures and geometry are preserved; the slope-following chassis filter remains in use.

Original material IDs used for Spa road contact: 45, 58, 59, 60, 65, 81 (pitlane/asphalt/road-extension surfaces). Painted decals, tyre grooves, grass and buildings are excluded. Silverstone kerbs use materials 44 and 56 (`Curb_new`, `curb`). Singapore kerbs use materials 185 and 186 (red/white kerb textures, confirmed from the source texture sheet). The surface index applies each renderer's X,-Z,Y mapping and Singapore's 2.1 scale; nearly vertical faces are excluded. Singapore kerb contacts also exclude geometry outside the authored road-height band.

Silverstone and Singapore sample these original kerb footprints at each tyre, feeding the existing damped four-wheel heave/roll/pitch system. A small position-dependent rib input changes with speed. Contact is geometric, not a blanket band around an approximate route. RB22/SF26 receive chassis feedback; independently animated wheel meshes still require the planned model edits.

Checks: `node tools/contact.test.mjs` tests continuous inclined planes, triangle/bin boundaries, coordinate transforms, height bands and wall exclusion. `python3 tools/surface_smoke.py` loads all three real track GLBs, checks hundreds of contact points, verifies four-wheel/body response and ride-update integration, confirms absence of kerb rumble away from kerbs, and compares old Spa raster height against mesh height. Camera tests and resource integrity checks also run. A complete player-driven lap, especially the reported black section, remains a visual acceptance check.

Validation result: real-model probes passed at 352 Silverstone kerb points, 362 Singapore kerb points and 356 Spa road points. The largest old-raster deviation across sampled Spa asphalt/pitlane/extension triangles was 41.50 world units; this includes peripheral paving and is not a measurement of the user's exact black-road location. All tested mesh contacts matched their source triangle height. No uncaught JavaScript errors occurred. Synthetic contact tests, four camera tests and all 28 resource checks passed.
